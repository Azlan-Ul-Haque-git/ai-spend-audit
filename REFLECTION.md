# Project Reflection

## Objective

The goal of this project was to build a SaaS-style AI spend optimization platform capable of analyzing AI tooling costs and generating optimization recommendations.

---

## Key Learnings

During development, I improved my understanding of:

- Next.js App Router
- Full-stack architecture
- Supabase integration
- Dynamic routing
- Component-driven design
- Production deployment workflows

---

## Challenges Faced

### 1. Supabase Integration
Configuring environment variables and database permissions required debugging and testing.

### 2. Dynamic Routing
Understanding Next.js dynamic route handling using `[id]` routes was initially challenging.

### 3. Production Deployment
Resolving dependency and deployment issues on Vercel improved my debugging workflow.

---

## What I Would Improve

If given more time, I would add:

- Authentication
- AI-generated recommendations
- PDF export
- Real-time analytics
- Team collaboration features

---

## Final Thoughts

This project helped me understand how modern SaaS products are structured and deployed in production environments.
